ABOUT THE PROJECT

Computer Vision Made Simple

FaceMask AI is a browser-based face mask detection application that combines computer vision with deep learning.

The system detects faces using OpenCV's Haar Cascade classifier and then sends the detected face through a trained TensorFlow CNN model to classify whether a mask is present.
